# React Photo Gallery

Responsive photo gallery built with React and the Pixabay API.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Add your Pixabay API key:
   ```bash
   cp .env.example .env
   ```
   Then set `VITE_PIXABAY_API_KEY` in `.env`.
3. Start development server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```
